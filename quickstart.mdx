Make your first edit to the starter, then check it in a local preview.

## Prerequisites

Use a local clone of this repository, Node.js 22 with npm, and internet access for the Mintlify CLI’s first download. You do not need an application API key to edit these documentation pages.

<Steps>
  <Step title="Edit a page">
    Open `index.mdx` and change a sentence or card description. Preserve its `title` and `description` frontmatter. For a new page, add its extensionless path to `docs.json`.
  </Step>
  <Step title="Start the preview">
    Run this command from the directory containing `docs.json`:

    ```bash
    npx --yes mint@4.2.970 dev
    ```

    Open `http://localhost:3000`. Check the edited text, sidebar and cards. Stop the preview with Ctrl+C when you finish.
  </Step>
  <Step title="Check before review">
    Run the source check and the pinned Mintlify checks:

    ```bash
    python3 scripts/check-docs.py
    npx --yes mint@4.2.970 broken-links
    npx --yes mint@4.2.970 validate
    ```

    Review the diff and CI results before merging. CLI validation and a visual review provide different evidence; a source link check alone does not verify the rendered site.
  </Step>
</Steps>
