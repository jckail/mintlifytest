This repository is a documentation starter for experimenting with Mintlify. You can edit MDX pages, organize the sidebar in `docs.json`, and preview your changes locally. The site keeps Mintlify’s original theme and assets while you learn the publishing workflow.

<Note>
  These pages describe the starter itself. No application backend, API reference or hosted project deployment is established by this repository.
</Note>
